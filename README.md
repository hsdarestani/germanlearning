# German Learning — Lernjournal

A persistent, source-linked German tutoring record for lessons with ChatGPT. **Language of explanations: Persian (فارسی); practice language: German (Deutsch).**

## Learning sources
1. **Klipp und Klar — Übungsgrammatik Grundstufe Deutsch in 99 Schritten** (Christian Fandrych, Ulrike Tallowitz). Main step-by-step grammar spine, 99 units.
2. **Practice Makes Perfect: Complete German Grammar, Premium Second Edition** (Ed Swick). Complementary explanations, exercises and reviews across 25 chapters.

The student has provided both books in ChatGPT. **Do not upload copyrighted book PDFs or reproduce whole exercises in this public repository**; store references (book, chapter / step, printed page) and original tutor-created activities instead.

## Class structure
Every lesson combines:
- **Sprechen (Speaking)**: interactive German dialogue, role-play, pronunciation coaching (use ChatGPT Voice when available).
- **Schreiben (Writing)**: original sentences, short messages and longer writing with specific corrections.
- **Hören (Listening)**: voice/listening activities and comprehension questions; avoid marking audio skills as tested unless actually tested.
- **Lesen (Reading)**: short German passages and comprehension.
- **Grammatik & Wortschatz**: learn a targeted rule using the two books, then apply it through original sentences.

A typical class: quick review → one grammar focus → guided speaking → writing/reading/listening → feedback → homework. Scale difficulty to actual demonstrated level, not self-reported level alone.

## Session tracking (source of truth)
- [PROGRESS.md](PROGRESS.md): verified current level and skill-specific progress; do not invent assessments.
- [CURRICULUM.md](CURRICULUM.md): book-to-book alignment and completion status.
- [NEXT_SESSION.md](NEXT_SESSION.md): **first file to read when resuming**; exact pending task.
- [MISTAKES.md](MISTAKES.md): recurring errors, examples, fixes and resolved status.
- [VOCABULARY.md](VOCABULARY.md): learnt words with article/plural where relevant, contextual examples and review state.
- [sessions/](sessions/): dated, numbered lesson notes, assessment evidence and assigned homework.

### End-of-session update protocol
1. Write or update the dated lesson note under `sessions/`.
2. Record what was **actually** covered, what the student independently demonstrated, corrections, homework and exercises not yet checked.
3. Update `PROGRESS.md` and `CURRICULUM.md` only for genuinely completed work.
4. Update `MISTAKES.md` and `VOCABULARY.md` only with observed examples, not guessed weaknesses or mastered vocabulary.
5. Update `NEXT_SESSION.md` **last** with one exact resumption point and next action.
6. Verify the changed files were committed successfully and share a short recap in chat.
